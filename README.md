The final status will only become 🟢 when the Android project builds successfully in CI and the core mail flows have been verified. Placeholder/demo functionality will not be marked complete.

## Current UI direction

- Pure AMOLED black base

- Work-account focused navigation
- Inbox, message detail and compose flows
- Calendar, Contacts and Tasks sections
- Account/mailbox management

## Planned mail engine

- IMAP account configuration

- Search and threaded conversations
- HTML email rendering
- HTML signature support
- Attachments
- Notifications/background synchronization
